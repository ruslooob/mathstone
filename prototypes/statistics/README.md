# Статистика · отдельный прототип

Оболочка для [задачи #16](https://github.com/ruslooob/mathstone/issues/16).
Общие требования находятся в [#15](https://github.com/ruslooob/mathstone/issues/15).
Прототип не подключён к приложению Mathstone. Первая содержательная глава — «Дисперсия и степени свободы».
Она заменяет тестовую заметку и рассчитана на повторение курса. Длительность — 84 секунды, семь шагов.
Глава включает геометрию суммы квадратов, вывод поправки Бесселя и точный перебор маленьких выборок.
Это часть темы #17, а не завершение всех четырёх глав этой задачи.
Это один вариант оформления: тетрадь в клетку со светлой областью для графика.

## Запуск

Из корня репозитория с установленными зависимостями:

```sh
npm run dev
```

Открыть http://127.0.0.1:5173/prototypes/statistics/.
Сервер Vite обрабатывает TypeScript и CSS-модули. Открытие HTML через `file://` не поддерживается.
Аккаунт, серверная часть и внешние ресурсы для просмотра не нужны.
Обычный `npm run build` собирает приложение Mathstone, а не этот прототип.

## Подключение главы

[chapter.ts](./chapter.ts) — единственный источник контракта.
[chapters/descriptive/index.ts](./chapters/descriptive/index.ts) — подключённая содержательная глава.
Её данные и вычисления находятся в [model.ts](./chapters/descriptive/model.ts).

1. Создайте свой каталог из таблицы ниже.
2. Экспортируйте из его `index.ts` именованную константу `chapters: readonly Chapter[]`.
3. Стройте каждый кадр из данных и абсолютного времени. Перемотка должна работать в любом порядке.
4. Используйте сигнал из контекста для обработчиков. Освободите остальные ресурсы в `dispose`.
5. Передайте агенту сборки путь экспорта. Он подключит главы в [registry.ts](./registry.ts).

Не запускайте `requestAnimationFrame`, таймеры, CSS-анимации или отдельные часы внутри главы.
Оболочка управляет воспроизведением. При уменьшенном движении глава показывает завершённый текущий шаг.
Текст и формулы должны читаться в этом режиме. Глава может выбирать вид сцены внутри общего оформления.

Длительность главы вычисляется из шагов в [timeline.ts](./timeline.ts). Не храните её отдельной копией.
На границе шагов показывается следующий шаг. В конце главы показывается последний кадр последнего шага.
Перемотка, переход по шагу, перезапуск и выбор главы останавливают воспроизведение.
При возврате из скрытой вкладки воспроизведение остаётся на паузе.

## Владение файлами

| Задача | Каталог |
| --- | --- |
| #16 — оболочка | файлы в корне прототипа, `shared/`, `registry.ts` |
| #17 — описательная статистика | `chapters/descriptive/` |
| #18 — распределения и ЦПТ | `chapters/distributions/` |
| #19 — интервалы и гипотезы | `chapters/inference/` |
| #20 — простая регрессия | `chapters/simple-regression/` |
| #21 — множественная регрессия | `chapters/multiple-regression/` |
| #22 — итоговая сборка | подключение модулей в `registry.ts` и проверка общего порядка |

Содержательные агенты не меняют общие файлы. Для локальной проверки можно временно подключить свой экспорт
в реестре, но не включать эту правку в свою поставку. При необходимости добавляйте CSS-модуль рядом с главой.

[shared/scene.ts](./shared/scene.ts) содержит общие цвета, текст, формулы, SVG и оси.
Тетрадный фон и светлая область графика определены в [statistics.module.css](./statistics.module.css).
Для сложных формул можно использовать нативный MathML. Не загружайте шрифты или библиотеки с CDN.

Данные и вычисления одного блока принадлежат его каталогу. Между блоками не копируйте вычисления.
Если общий математический модуль потребуется нескольким агентам, сначала назначьте одного владельца
и согласуйте экспорт в `shared/`. Оболочка пока не содержит статистической библиотеки.
Симуляции должны хранить seed и восстанавливать результат независимо от порядка просмотра кадров.

## Проверки

Из корня репозитория:

```sh
npx tsc -p prototypes/statistics/tsconfig.json
npm run lint
npx stylelint "prototypes/statistics/**/*.css"
npx prettier --check "prototypes/statistics/**/*.css"
npx playwright test --config prototypes/statistics/playwright.config.ts
```

Отдельная конфигурация проверяет широкий и узкий экран. Она запускает Vite или использует уже работающий сервер.
Тесты проверяют перемотку, шаги, скорость, паузу, конец главы, клавиатуру, уменьшенное движение и очистку ресурсов.
Отдельные проверки сверяют числовой пример, разложение суммы квадратов и несмещённость по полному перебору выборок.
Переключение между двумя тестовыми главами проверяется только в тесте. В интерфейсе нет дополнительных вариантов дизайна.
