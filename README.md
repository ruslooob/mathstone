# Вижу → решаю

Концепция будущего MVP находится в [MVP_BRIEF.md](../MVP_BRIEF.md). Она определяет целевую механику наград. Этот README описывает существующий прототип.

Полностью локальное приложение с двумя уроками: определители матриц 2×2 и 3×3. Код HTML, CSS, JavaScript и локального запуска находится в этой папке. Его можно редактировать, копировать и переносить на другой компьютер.

Проект должен работать исключительно локально. Не публиковать его, не выгружать исходники и не подключать облачные сервисы без явного нового указания владельца. Интернет, учётная запись и Sites для запуска не нужны. Внешних шрифтов, аналитики, CDN и сетевых API нет.

В каждом уроке — пошаговая анимация с управлением воспроизведением, визуальная карточка и три самостоятельные задачи. Схема для 3×3 показывает диагонали и треугольники внутри исходной матрицы. Подсказки доступны во время решения. Решать предполагается на бумаге или в привычном редакторе.

## Запуск

Дважды щёлкнуть `start.cmd` — локальный сервер запустится и откроет приложение в браузере. Нужен установленный Python 3; сторонних пакетов нет.

Или из этой папки:

```powershell
python run.py
```

Приложение доступно на http://127.0.0.1:8766. Сервер слушает только локальный адрес 127.0.0.1. Чтобы остановить его, нажать Ctrl+C в окне сервера. Установка зависимостей и сборка не нужны.

Если порт занят: `python run.py --port 8767`. Для запуска без автоматического открытия браузера: `python run.py --no-browser`.

Нажать «Смотреть» над матрицей: первое действие начинается сразу. Эта же кнопка ставит анимацию на паузу и продолжает её. Стрелки позволяют перейти к отдельному шагу.

Все этапы доступны сразу: можно открыть карточку или перейти к задачам без обязательного просмотра. Открытая карточка добавляется в коллекцию. Кнопка «Забрать карточку» работает с первого кадра.

Состояние уроков и карточек хранится в памяти вкладки и сбрасывается при обновлении страницы. Учётных записей и хранения пользовательских данных нет.

## Проверка

```powershell
node --check dist/app.js
```

Проверены в браузере оба учебных маршрута, верные и неверные ответы, подсказки, коллекция, повтор урока и мобильная раскладка.

`checks/playback.browser.js` — проверка воспроизведения на реальной странице через Playwright. Она проверяет немедленное начало движения после Play, паузу, продолжение и автоматическое завершение обоих уроков. Причина исправленной остановки: первый кадр не содержал движения, а таймер ждал 6,5 секунды до перехода к вычислению.

`checks/navigation.browser.js` — проверка прямого доступа к карточке и задачам, получения карточки с первого кадра, перехода из карточки в практику и возврата из коллекции. Обязательное ожидание конца анимации удалено.
