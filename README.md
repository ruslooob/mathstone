# Вижу → решаю

Рабочий прототип двух уроков: определители матриц 2×2 и 3×3.

В каждом уроке — пошаговая анимация с управлением воспроизведением, визуальная карточка и три самостоятельные задачи. Схема для 3×3 показывает диагонали и треугольники внутри исходной матрицы. Подсказки доступны во время решения. Решать предполагается на бумаге или в привычном редакторе.

## Запуск

Из этой папки:

```powershell
python -m http.server 8766 --bind 127.0.0.1 --directory dist
```

Открыть http://127.0.0.1:8766. Установка зависимостей и сборка не нужны. Для шрифтов используется Google Fonts; без сети работают системные шрифты.

Состояние уроков и карточек хранится в памяти вкладки и сбрасывается при обновлении страницы. Учётных записей и хранения пользовательских данных нет.

## Проверка

```powershell
node --check dist/app.js
```

Проверены в браузере оба учебных маршрута, верные и неверные ответы, подсказки, коллекция, повтор урока и мобильная раскладка.
