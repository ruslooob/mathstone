# Mathstone

Локальное React-приложение на TypeScript: уроки по определителям матриц 2×2 и 3×3.
В каждом уроке есть анимация, шпаргалка со схемой и три самостоятельные задачи.
Внешние шрифты, CDN, аналитика и сетевые API не используются.

## Требования

- Windows, Linux или macOS.
- Node.js 20.19+ в ветке 20 либо Node.js 22.12+ и npm.
- GNU Make для команды `make`. На Windows команды `node`, `npm` и `make` должны быть в PATH.
- Интернет при первой установке зависимостей. Версии закреплены в `package-lock.json`.

Python для запуска не нужен.

## Запуск и остановка

Из корня mathstone:

```sh
make
```

Первый запуск устанавливает зависимости через `npm ci` и запускает Vite.
Открой http://127.0.0.1:5173 в браузере. Сервер слушает только адрес 127.0.0.1.
Остановка: Ctrl+C в терминале сервера.

Следующие запуски с установленными актуальными зависимостями работают без интернета.
Make повторяет `npm ci`, если изменён `package.json` или `package-lock.json` либо удалён `node_modules`.
После смены версии Node.js или платформы выполни `npm ci` вручную.
Все зависимости приложения находятся на компьютере.
Установка пакетов и само приложение не требуют учётной записи.

Без Make доступны те же действия:

```sh
npm ci
npm start
```

`npm start` и `npm run dev` запускают Vite после установки зависимостей.
`make install` устанавливает зависимости, только если установка отсутствует или файлы зависимостей изменились.
Порт 5173 должен быть свободен. При занятом порте Vite завершится с сообщением об ошибке.

## Поведение уроков

Кнопка «Смотреть» сразу запускает первый шаг вычисления. Она же ставит анимацию на паузу и продолжает её.
Шкала и клавиши ← и → позволяют выбрать шаг. Между шагами проходит две секунды.
При скрытии вкладки воспроизведение останавливается.

Все этапы доступны сразу. Открытие шпаргалки добавляет её в коллекцию.
Кнопка «Забрать шпаргалку» доступна с первого кадра. Решение трёх задач также выдаёт шпаргалку.
Шпаргалка доступна во время решения, даже если она ещё не получена.
Прогресс и награды хранятся только в памяти вкладки. Обновление страницы сбрасывает их.
Это текущее поведение приложения. Изменение наград относится к задаче № 6.

## Проверки

```sh
npm run lint
npm run typecheck
npm run build
```

`lint` проверяет JavaScript, TypeScript, React и конфигурацию по правилам Airbnb, а CSS — через Stylelint и Prettier.
Предупреждения также останавливают проверку.
`npm run lint:fix` исправляет нарушения ESLint и форматирует CSS.
Правила проекта описаны в [CODING_STANDARDS.md](CODING_STANDARDS.md).

`typecheck` проверяет TypeScript в строгом режиме. `build` повторяет проверку типов и создаёт статическую сборку в `dist/`.

Существующие проверки воспроизведения и навигации подключены к Playwright.
Они проверяют оба урока при ширине 1440 и 390 пикселей.
Для первого запуска нужен Chromium для Playwright:

```sh
npx playwright install chromium
npm test
```

На Linux при отсутствии системных библиотек используй `npx playwright install --with-deps chromium`.
После установки браузера проверки работают локально. Сервер на порту 5173 перед проверками нужно остановить.
Отдельные проверки:

```sh
npm run test:playback
npm run test:navigation
```

По указанию владельца при переносе приложения браузерные проверки не запускались.

## Сборка

```sh
make build
make preview
```

Или `npm run build`, затем `npm run preview` после установки зависимостей.
Предпросмотр доступен на http://127.0.0.1:5173. Остановка: Ctrl+C.
Это локальный предпросмотр. Публикация автоматически не выполняется.
