## Общие правила

- Всегда общайся с пользователем простым русским языком. Используй скилл asd-ste100.
- В конце сессии удаляй временные файлы. Не оставляй после себя мусор.
- В github-issues записывай только результат окончательных решений, а не промежуточный.
- При оставлении сообщений в github предваряй их пометкой (ai), чтобы можно было понять кто написал это сообщение.
- Перед реализацией пользовательского интерфейса обсуди с пользователем формулировки надписей, расположение элементов
  управления, цветовую схему и так далее. Можешь отступать от этого правила после явного согласования с пользователем (
  например при прототипировании).
- Используй методологию [conventional commits](https://www.conventionalcommits.org/en/v1.0.0/), когда делаешь коммиты.
