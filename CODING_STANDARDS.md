# Правила кода

Для JavaScript и TypeScript используй [Airbnb JavaScript Style Guide](https://github.com/airbnb/javascript).
Для компонентов React используй [Airbnb React Style Guide](https://github.com/airbnb/javascript/tree/master/react).
Запускай `npm run lint` перед коммитом. Для автоматических исправлений используй `npm run lint:fix`.

Не использовать ascii-символы в качестве иконок. Использовать только качественные иконки.
